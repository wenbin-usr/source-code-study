# Nginx 深入剖析 · 总览与阅读指南（基于 nginx-1.27.0）

> 本目录是根目录 [nginx-底层实现原理清单.md](../nginx-底层实现原理清单.md) 的逐模块展开版：每个模块一篇独立文档，全部基于真实源码行号精读（引用格式 `文件:起始行-结束行`，可直接点开对照），配 mermaid 架构图 / 流程图 / 状态机 / 时序图。
>
> **规模**：29 篇专题文档，约 2.4 万行，226 幅 mermaid 图。
> **统一结构**：每篇九节 —— ①模块定位（架构图）②数据结构逐字段精讲 ③初始化流程图 ④核心执行流程/状态机 ⑤关键时序图 ⑥源码逐段精读（主体，占一半以上篇幅）⑦设计思想与权衡 ⑧配置项与调优映射 ⑨自测题（含答案）。

## 使用方法

1. 先读根目录的总清单建立全景，再按下面三条路线进入本目录精读。
2. 每篇文档都请**开着源码对照读**（VS Code 打开 nginx-1.27.0 仓库，跳到文中引用的 `文件:行号` 验证一遍，印象深十倍）。
3. 读完每篇先做第 9 节自测题，答不上来的回第 6 节重读；三篇一小组，组间做根清单第 24 节的对应问题。
4. 行号均对应 **nginx-1.27.0**；换版本后行号会漂移，函数名不会，按函数名 grep 即可重新定位。
